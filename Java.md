### Equivalence Testing with LinkedList
Pre linked list sa da vykonat iba prejdenie celeho listu a porovanie jednotlivych elentov pomocou .equals() funkcie

```java
public boolean equals(Object o) {  
    if (o == null) return false;  
    if (this.getClass() != o.getClass()) return false;  
    SinglyLinkedList other = (SinglyLinkedList) o;  
    if (this.getSize() != other.getSize()) return false;  
    Node walkA = this.head;  
    Node walkB = other.head;  
    while (walkA != null) {  
        if (!walkA.getElement().equals(walkB.getElement())) return false;  
        walkA = walkA.getNext();  
        walkB = walkB.getNext();  
    }  
    return true;  
}
```
### Cloning Data Structures
**Shallow copy** - je zabezpecena operatorom priradenie '='. Pri referencnych typoch vytvori novu referenciu, ktorou modifikujeme povodny objekt (Shared pointer)

**Deep copy** - je zabezpecene funkciou Object.clone(), ktora je protected. Ked chceme vytvorit kopiu, musime implementovat vlastnu clone() metodu a implementovat Cloneable interface 

Ked pouzijeme .clone() na array, ktory ma vsebe referencne typy, tak vytvorime iba nove referencie, ktore stale odkazuju na povodne objekty.
```java
Person[] guests = new Person[contacts.length];
for (int k = 0; k < contacts.length; k++) {
	guests[k] = contacts[k].clone();    // returns Object type
}
```

Pokial mame 2-rozmerne pole, tak musime opat vykonat podobny princip na vytvorenie klona
```java
public static int[][] deepClone(int[][] original) {
	// create top-level array of arrays
	int[][] backup = new int[original.length][];
	for (int k = 0; k < original.length; k++) 
		backup[k] = original[k].clone( ); // copy row k
	return backup;
}
```

Klonovanie SinglyLinkedList implements Cloneable
```java
public SinglyLinkedList<E> clone() throws CloneNotSupportedException {  
    // always use inherited Object.clone() to create the initial copy  
    SinglyLinkedList<E> other = (SinglyLinkedList<E>) super.clone();  
    if (this.size > 0) {// we need independent chain of nodes  
        other.head = new Node<>(this.head.getElement(), null);  
        Node<E> walk = this.head.getNext();// walk through remainder of original list  
        Node<E> otherTail = other.head;// remember most recently created node  
        while (walk != null) {// make a new node storing same element  
            Node<E> newest = new Node<>(walk.getElement(), null);  
            otherTail.setNext(newest);// link previous node to this one  
            otherTail = newest;  
            walk = walk.getNext();  
        }  
    }  
    return other;  
}
```
